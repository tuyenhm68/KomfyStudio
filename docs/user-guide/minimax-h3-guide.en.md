## Overview

**MiniMax H3** is an open-source AI video generation model developed by MiniMax. KomfyStudio integrates MiniMax H3 with an All-in-One interface, allowing you to generate high-quality videos directly on your personal computer — no API costs, no generation limits.

| Mode | Function | Input |
|------|----------|-------|
| **T2V** | Text to Video | Text prompt |
| **I2V** | Image to Video | First/last frame images + prompt |
| **R2V** | Reference to Video | Reference images + videos + audio |
| **Audio Drive** | Lip-sync | Audio track + speaker photo |
| **Keyframes** | Morph through keyframes | Images at specified frames |
| **Extend** | Extend existing video | Source video |
| **Chain** | Multi-clip continuous video | Sequential prompts |
| **Music** | AI music generation | Caption/lyrics |

> 💡 **Special**: Videos generated by MiniMax H3 **include native audio** — no need for a separate audio generation step.

---

## System Requirements

- **GPU**: NVIDIA GPU with **VRAM ≥ 24GB** (RTX 4090, RTX 3090, A5000, etc.)
- **RAM**: Recommended 32GB+
- **Storage**: ~30GB for models (automatically downloaded on first run)
- **Backend**: ComfyUI Local (ComfyUI Portable or equivalent must be installed)

> ⚠️ **Note**: MiniMax H3 requires a powerful GPU. If your GPU has less than 24GB VRAM, you can use Turbo mode (fewer steps) or reduce the resolution.

## Getting Started

### Step 1: Open MiniMax H3

1. Launch **KomfyStudio** and ensure the **ComfyUI backend** is running
2. Switch to the **Apps** tab (grid icon in the sidebar)
3. Select **MiniMax H3** from the apps list (under Video category)

### Step 2: Choose a Mode

The mode bar at the top displays 8 modes:

**T2V** · **I2V** · **R2V** · **Audio** · **Keys** · **Extend** · **Chain** · **Music**

Click the mode you want to use.

### Step 3: Enter Content and Generate

1. Enter a **prompt** describing the video (English works best)
2. Upload input files depending on the mode (images, videos, audio)
3. Click the **Generate** button in the bottom bar

> 💡 **Tip**: On first run, KomfyStudio will automatically download the required models (~30GB). This only happens once.

## Video Generation Modes

### Text to Video (T2V)

Generate video entirely from a text description.

**Input**: Prompt only

**How to use**:
1. Select **T2V** mode
2. Enter a prompt describing the video scene, e.g.:
   ```
   A cat walking on the beach at sunset, waves crashing in the background, 
   cinematic lighting, 4K quality
   ```
3. Click **Generate**

---

### Image to Video (I2V)

Convert static images into dynamic video.

**Input**: First Frame and/or Last Frame image + prompt

**How to use**:
1. Select **I2V** mode
2. Upload **First Frame** (starting image) — *optional*
3. Upload **Last Frame** (ending image) — *optional*
4. Enter a prompt describing the desired motion
5. Click **Generate**

> 💡 **Tip**: You can upload only the First Frame, only the Last Frame, or both. When both are provided, the video morphs from the first image to the last.

---

### Reference to Video (R2V)

Use reference images/videos/audio to create a new video.

**Input**: Reference images + Reference videos + Reference audio (all optional)

**How to use**:
1. Select **R2V** mode
2. Upload **Reference Images** — character/identity photos
3. Upload **Reference Videos** — motion reference
4. Upload **Reference Audios** — background soundtrack
5. Enter a prompt
6. Click **Generate**

**What each reference means**:
- **Image** = defines character/identity
- **Video** = defines motion/movement
- **Audio** = final soundtrack

---

### Audio Drive

Automatic lip-sync — audio drives the character's mouth movements.

**Input**: Audio file (required) + speaker photo (optional)

**How to use**:
1. Select **Audio** mode
2. Upload **Audio Track** — speech/audio file *(required)*
3. Upload **Speaker Photo** — image of the speaker
4. Enter additional prompt (if needed)
5. Click **Generate**

> 💡 **Tip**: Upload a clear face photo for more accurate lip-sync results.

---

### Keyframes

Create video that morphs through specified keyframe images.

**Input**: Images at frame positions + prompt

**How to use**:
1. Select **Keys** mode
2. Add keyframes by clicking **+ Add Keyframe**
3. Specify the **frame number** and upload an **image** for each keyframe
4. Enter a prompt describing the transitions
5. Click **Generate**

The video will morph through the images in the order of the specified frames.

---

### Extend

Extend an existing video by a few more seconds.

**Input**: Source video (required) + prompt

**How to use**:
1. Select **Extend** mode
2. Upload **Video to Extend** — the video to continue *(required)*
3. Enter a prompt describing what should happen next
4. Click **Generate**

---

### Chain

Generate multiple clips in sequence and stitch them end-to-end with motion continuity.

**Input**: List of prompts for each clip

**How to use**:
1. Select **Chain** mode
2. Each clip has its own prompt field — enter a description for each segment
3. Adjust the **duration** for each clip (in seconds)
4. Add/remove clips using the **+** / **-** buttons
5. Click **Generate**

> 💡 **Tip**: Clips are stitched end-to-end with motion-context continuity — smooth transitions between segments.

---

### Music

Generate AI music using MiniMax Music 3.

**Input**: Caption (description) and/or Lyrics

**How to use**:
1. Select **Music** mode
2. Enter **Caption** — music style description (e.g., *"Upbeat electronic dance music with synth pads"*)
3. Enter **Lyrics** — song lyrics (if you want vocals)
4. Adjust **duration** (default 60 seconds)
5. Click **Generate**

## Advanced Settings (TUNE)

Expand the **TUNE** section to customize:

| Parameter | Description | Default |
|-----------|-------------|---------|
| **Resolution** | Video resolution | 960×544 (0.5MP) |
| **Duration** | Video duration (seconds) | 5s |
| **Steps** | Inference steps | 20 |
| **Quality** | Quality mode (native / turbo) | native |
| **Sampler** | Sampling algorithm | res_multistep |
| **Scheduler** | Noise schedule | simple |
| **Seed** | Seed value (0 = random) | 0 (random) |
| **Batch** | Number of videos to generate | 1 |

**Common resolutions**:
- `960×544` — 0.5MP Balanced (default, fast)
- `1280×720` — 720p HD
- `1920×1080` — 1080p Full HD (requires more VRAM)

> ⚠️ **Note**: Increasing resolution and steps will require more VRAM and processing time.

## LoRA

Expand the **ADVANCED** section to manage LoRAs:

1. Click **+ Add LoRA**
2. Select a LoRA file from the list (must be placed in `models/loras/`)
3. Adjust **strength** (0.0 – 2.0)
4. You can add multiple LoRAs simultaneously

If using **Turbo** quality mode, you need to select a corresponding **Speed LoRA**.

---

## Video Upscale

After generating a video, you can upscale its resolution:

1. Switch to **Upscale** mode (if available)
2. The recently generated video will be automatically selected as input
3. Click **Generate** to upscale

## Troubleshooting

### ❌ "Out of memory" or CUDA OOM

- Reduce **Resolution** to 960×544 or lower
- Reduce **Steps** to 15-20
- Close other applications using the GPU
- Use **Turbo** mode if available

### ❌ Models not downloaded

- On first run, models will download automatically (~30GB). Ensure a stable internet connection.
- Check available disk space

### ❌ Video generated but not displaying

- Check the console log (F12) for error messages
- Ensure the ComfyUI backend is still running
- Try generating again with a simpler prompt

### ❌ Low video quality

- Increase **Steps** to 25-30
- Use **Native** quality mode instead of Turbo
- Write more detailed prompts in English
